FMG DCF Monitor v4 — Sustainable Growth
v4 replaces Yahoo's short-term earnings growth with a sustainable growth rate:
SGR = ROE × Retention Ratio
Retention Ratio = 1 − Payout Ratio
On every scheduled run the monitor fetches the CURRENT ROE and CURRENT payout ratio
from StockAnalysis/S&P Global. Therefore the sustainable growth rate automatically
changes when Fortescue's financial metrics change after new results.
The rest of the model remains:
rolling 7-year average FCF/share
USD→AUD conversion
15% required return
10-year forecast
GuruFocus 10-year median P/E terminal multiple
email when FMG crosses below calculated intrinsic value
The dashboard now displays ROE, payout ratio, retention ratio and sustainable growth rate.
